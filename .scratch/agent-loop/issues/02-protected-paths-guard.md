# 02: Strażnik chronionych ścieżek

**What to build:** Implementer nie może zmienić chronionej ścieżki ani dodać wyciszenia analizatora, żeby
„zbiec” przez osłabienie reguł. Zapis przez Edit i Write jest odrzucany od razu. Zapis dowolnym innym
narzędziem (także przez Bash), dodane wyciszenia i zmiany w istniejących testach wychodzą w sprawdzeniu diffu
zakresu commitów ticketu, które weryfikator uruchamia jako skrypt. Lista ścieżek pochodzi z pliku DoD.

**Blocked by:** 01

**Seams:** hook `PreToolUse` jako proces (jak w 01) oraz skrypt sprawdzenia diffu jako proces. Wejście:
repozytorium z commitami w katalogu tymczasowym i zakres commitów. Wyjście: lista naruszeń i kod wyjścia.
Testy xUnit w projekcie testów hooków z 01.

**Status:** done

- [x] `PreToolUse` odrzuca Edit i Write implementera do każdej ścieżki z listy w pliku DoD i przepuszcza zapis
      poza listą. Lista na start: `.editorconfig`, `Directory.Build.props`, testy architektury, `AGENTS.md`,
      ADR-y, konfiguracja agenta (historia 18).
- [x] `PreToolUse` przepuszcza zapis do chronionej ścieżki, gdy `agent_type` nie jest rolą implementera, więc
      orkiestrator może po bramce 2 wprowadzić przyjęte konwencje (historia 39).
- [x] Skrypt diffu zgłasza zmianę chronionej ścieżki w zakresie commitów, niezależnie od narzędzia, którym
      powstała (historia 19).
- [x] Skrypt diffu zgłasza dodane wyciszenia: `#pragma warning disable`, `[SuppressMessage]`, `<NoWarn>`,
      `<WarningsNotAsErrors>`, wyłączenie `TreatWarningsAsErrors`, `CodeAnalysisTreatWarningsAsErrors`,
      `RunAnalyzers` albo `EnableNETAnalyzers` oraz zmiany poziomów w `.editorconfig` (historia 32).
- [x] Skrypt diffu nie zgłasza plików wygenerowanych przez narzędzia (pierwsza linia `// <auto-generated />`)
      ani istniejących wyciszeń bazowych template'u.
- [x] Skrypt diffu wypisuje zmodyfikowane (nie dodane) pliki testów jako „do oceny weryfikatora” (historia 24).
- [x] Zmiana listy w pliku DoD zmienia działanie hooka i skryptu bez zmiany ich kodu.
