## 6. Środowisko i pułapki, które kosztowały czas

- **Porównanie plików między repo:** `diff -q` pokazuje każdy plik jako różny przez końce linii. Używaj
  `diff -q --strip-trailing-cr`.
- **`git show <rev>:<ścieżka>` w Git Bash** zamienia argument na ścieżkę Windows. Poprzedź `MSYS_NO_PATHCONV=1`.
- **`/model` w sesji** przełącza model na stałe; po przełączeniu raz wystąpił `ECONNRESET`, wystarczyło
  „Try again”.
- **Skill tool odmawia skilla z `disable-model-invocation`.** `/plan-feature` i `/ship` wpisuje użytkownik.
- **Tryb auto blokuje edycję `.claude/settings.json`.** Wpisy allowlisty (kandydaci z pilota) dopisuje
  użytkownik, a Ty sprawdzasz plik na dysku.
- **Długie wpisy po polsku** dopisuj przez Edit albo Write, nie przez heredoc w Bash.
- **Fork:** po zmianie podbij wersję w `.claude-plugin/plugin.json`, potem `claude plugin marketplace update
  mattpocock` i `claude plugin update mattpocock-skills@mattpocock`; bieżąca sesja nie widzi nowej wersji;
  `claude plugin validate . --strict` ma dwa stare ostrzeżenia (`CLAUDE.md` w korzeniu, brak ikony).
- **Build i testy** łańcuchem z `set -o pipefail`; Docker sprawdzasz przez
  `pwsh -NoProfile -NonInteractive -File .claude/hooks/run-dod.ps1 -Check environment` (narzędziem PowerShell).
- **Python nie jest zainstalowany.** Skrypty pisz w `node`.
- **Sesja w worktree** odrzuca złożone polecenia `git` i każde `pwsh` w Bashu; skrypty idą narzędziem
  PowerShell.
